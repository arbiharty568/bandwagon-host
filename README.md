# 搬瓦工套餐怎么选：从机房、配置到费用

选择海外 VPS，第一步不是寻找参数最大的套餐，而是弄清服务器放在哪里、谁需要访问它，以及准备承担多长时间的费用。搬瓦工（BandwagonHost）的产品既有以年付为主的普通 KVM 套餐，也有不同机房和计费周期的 CN2 GIA 套餐；即使内存与硬盘相同，线路和价格也可能不同。

这份指南按照用途、机房、配置和购买流程整理主要选择。表格中的配置与价格可用于建立比较基准，实际可购买的方案、机房和订单金额应在下单页面核对。也可以先浏览[搬瓦工官网套餐总览](https://bwh81.net/aff.php?aff=85071)，再回到表格比较具体产品。

## 搬瓦工是什么，适合哪些需求

搬瓦工是加拿大 IT7 Networks 旗下的 VPS 品牌，产品采用 KVM 虚拟化。VPS 可以理解为在物理服务器上划分出的虚拟服务器：用户选定套餐后，获得对应的计算、存储和网络资源，再根据自己的用途配置系统和软件。它与只需上传文件即可使用的托管空间不同，使用者仍需考虑系统维护、数据备份和服务配置。

KiwiVM 控制面板提供系统重装、快照、备份、流量查看和机房切换等管理功能。面板能帮助用户完成常见管理操作，但不代表不需要了解所部署的软件和服务器安全设置。准备重装系统或恢复数据时，也应先弄清操作会影响哪些文件。

如果只是需要一个海外 Linux 环境，可以优先比较普通 KVM 的成本和资源；如果访问者主要在中国大陆，线路与机房则值得放在配置之前考虑。对服务保障有明确要求的使用者，可以进一步阅读 SLA Plan 的条款，而不是仅凭套餐名称判断是否满足业务需要。

## 搬瓦工机房怎么选

### 先区分位置、线路与套餐权限

机房位置决定服务器所在地区，线路名称描述网络连接方案，套餐权限则决定实际能够选择哪些机房。三者有关联，却不是同一个概念：购买某类线路套餐，不等于能自由选择所有地区；同在洛杉矶的机房，也不应只凭城市名称假设连接方式完全相同。

普通 KVM 套餐以洛杉矶机房为主要选择，价格相对较低；CN2 GIA-E 提供更多可选机房，选项包括洛杉矶 DC6、DC9，以及软银和荷兰等机房。香港 CN2 GIA 套餐则面向希望选择香港机房的用户。SLA Plan 使用 DC5，并提供特定的服务保障条款。购买前应在对应产品页面确认实际开放的选项，不要把一个套餐的机房列表套用到另一款。

访问者所在地区、使用的网络以及访问时段都可能影响连接体验。线路名称可以帮助缩小选择范围，但不能单独证明每个人的延迟或速度。若连接质量是关键条件，宜结合实际访问地点和使用时间进行测试，并把测试结果与预算一起考虑。

### 迁移范围和流量需要一起看

荷兰 EUNL_1 机房仅限 CN2 GIA-E 套餐新购时选择，已有套餐无法迁移过去。若荷兰是购买的主要原因，应在新订单的机房选项中确认，而不是先买其他机房、再假定日后可以切换。

流量规则同样会影响选择：普通 KVM 套餐切换至 DC3 CN2 时，月流量缩减为原来的三分之一；CN2 GIA-E 在其可选机房的流量不打折。因此，比较时不仅要看表格中的标称流量，还要确认准备使用的机房对应多少额度。切换之前先检查当前套餐的规则，并备份重要数据。

### 如何读懂配置

内存和 CPU 是运行系统与应用时要考虑的资源。先列出准备运行的软件，再查看它们的资源要求，比单纯按套餐名称判断更有依据。20G、40G 和 80G 这类名称对应表中的存储容量，不能只看名称就忽略内存和 CPU 的差异。

存储空间需要容纳系统、应用、数据及日常产生的文件；如果准备保存备份，也要考虑备份放在哪里。月流量是一个计量周期内的数据传输额度，带宽则是连接速率的指标，二者不能互相替代。带宽数字较高，不意味着月流量无限，也不意味着所有访问都能达到该速率。

比较价格时要同时看金额和周期。例如季付与年付的数字不能直接当作同一时期的支出；先按预计使用时长比较，再考虑一次支付的金额是否合适。年付套餐可能降低频繁续费的麻烦，但也意味着更长的预付周期。表中没有列出某个周期，并不代表产品一定不提供该周期，应以订单选项为准。

## 按实际需求缩小范围

**预算优先，只需要海外环境。** 可以从 KVM 入门版开始核对：1 GB 内存、20 GB 存储和年付价格是否符合计划。若需要更多内存、存储或月流量，再比较大流量版及其半年付、年付费用。普通套餐切换到 DC3 的流量变化也要算进选择中。

**希望比较线路与多个机房。** CN2 GIA-E 系列提供三个表列配置，资源从 1 GB 内存、20 GB 存储递增到 4 GB 内存、80 GB 存储。先确认目标机房在产品页面可选，再按照软件需求和流量预算挑配置；不要仅因为机房数量多就购买用不到的资源。

**有明确的服务保障要求。** SLA Plan 使用 DC5，提供 99.99% 保障，以及每两周一次免费更换 IP。是否适合业务，应进一步核对保障的适用条件、换 IP 规则与实际订单条款。一般套餐的换 IP 可能产生额外费用，不宜把 SLA Plan 的条件视为所有套餐通用。

**明确需要香港机房。** 两款香港 CN2 GIA 套餐分别提供 500 GB 和 1 TB 月流量，内存与存储也不同。除了比较配置，还应同时计算月付与年付支出，确认 HK3、HK8 等机房在所选产品中的实际可用情况。香港方案的成本明显不同于表中的普通 KVM 入门方案，是否值得取决于用途和预算。

## 购买前核对，开通后管理

1. **核对订单内容。** 从表中对应的产品链接进入，检查内存、CPU、存储、流量、机房选项和库存；选定计费周期后查看订单总价。若需要长期使用，也要查看续费价格和续费条件，避免只比较首次支付金额。
2. **检查附加规则。** 确认所选机房的流量额度、可切换范围和更换 IP 的费用或条件。常规优惠码已取消，不应把折扣作为必然可用的预算前提。
3. **记录开通信息并查看状态。** 服务开通后，进入 KiwiVM 检查服务器状态、流量和当前机房，再按需要选择系统。面板提供管理入口，但系统内的软件配置仍需要自行完成。
4. **建立备份习惯。** 使用快照或备份功能前，先确认其适用范围和恢复方式；重要数据应有可用的备份。重装系统、恢复快照或更换机房之前，检查数据是否已经保存，并确认套餐允许切换到目标机房。
5. **出现异常时先收集信息。** 查看面板中的服务状态和流量，记录出现问题的时间及现象，再通过服务商支持渠道咨询。涉及网络连接或 IP 的问题，也应先确认相关服务和费用条款。

选购的顺序可以概括为：先确定用途与访问地区，再确认机房和线路，最后比较资源、计费周期及长期费用。这样即使套餐页面发生变化，也能用同一套问题重新判断哪一项更符合自己的需求。
